# Meta Ads Playbook — operating rules

Source: 5 Sergio C (ADVT Media) videos, Sep 2026. Figures are the creator's client claims.
Companion files: `Meta_Ads_Playbook.pdf` (visual summary), `Meta_Ads_Client_OS.xlsx` (checklists + trackers).

## Core model
- Revenue = (Spend ÷ CPC) × Conversion rate × AOV. Move one lever at a time; pick the cheapest.
- ROAS is an output. Diagnose top-down and fix the FIRST failing stage only.
- Control beats volume: concentrate budget on proven ads; creative volume only pays at $1,000+/day.

## Benchmarks (thresholds)
| Stage | Metric | Healthy |
|---|---|---|
| Attention | CTR (all) | ≥ 2% (aim 3%+) |
| Interest | Link CTR ÷ CTR (all) | ≥ 50% |
| Cost | CPM | ~$28–30 (new pixel $50–70) |
| Page load | LPV ÷ link clicks | small gap (≈90%, assumption) |
| Buying intent | Add-to-cart ÷ LPV | ≥ 10% |
| Cart | Checkout ÷ ATC | ≥ 50% |
| Checkout | Purchase ÷ checkout | ≥ 50% |
| Economics | ROAS vs break-even | ≥ 1.0×; scale above ~1.5× break-even |

## Stairway (one variable per step)
1. Creative test — Sales/Purchase, campaign budget, broad, "acquire new customers", dynamic creative + catalog off, ignore campaign score. Rule: turn each ad off at 1,000 impressions (800 new pixel, 2–3k if budget allows). Days = ads × CPM × cap/1000 ÷ daily budget.
2. Copy test — only if link CTR < 50% of CTR; #1 ad, one copy per ad set (~$15/day, ~$200).
3. Landing page test — home vs collection vs product vs custom page (~$100 each).
4. Audience test — one interest per ad set ($10–20/day); target what buyers do (matcha/yoga > Lululemon); stack only proven interests.
5. Scale — ASC "winning assets" + interests; +$10–20/day steps; tests stay in a side campaign.

## Winners
- Must reach the impression cap, pass CTR / link-CTR benchmarks, and show buying behaviour. 5x on $12 ≠ winner; "most sales" ≠ winner if it was the only ad funded.
- Existing accounts: sort ad level by spend, not ROAS; cut ads with meaningful spend above target CPA; retest low-spend "shadow" ads.
- Allocation: #1–3 prospecting; next best → middle/bottom retargeting if CTR ≥ 2%.

## Creative
- Mine customer words (reviews, comments, tickets, surveys, Reddit, competitor reviews): want / blocker / tried.
- One problem, one angle, one sentence per ad; prove every claim visually; format follows message.
- Decode winners: format, idea, hook, selling point, funnel numbers, landing-page match.
- High CTR can lie (10.9% CTR ad sold nothing; 6.3% demo sold). Real beats polished.
- Branch winners one change at a time: hook, creator, format, offer/CTA, message, angle.

## Structure & budget
- Ads live vs budget: ~$30/day → 1–3; $100–700 → 2–5 winners; $1,000+ → volume + weekly tests.
- 80–90% prospecting, 10–20% retargeting. Middle = 50% video viewers + engagers, excl. site visitors 180d & purchasers 730d (judged on clicks). Bottom = ATC/visitors/purchasers 180d, excl. purchasers 30d (reviews, unboxing, 5% off 24h).

## Economics & scaling
- Break-even ROAS = AOV ÷ (AOV − product − fulfilment − fees). Example $100 / $60 = 1.67.
- Don't chase vanity ROAS (8x) when 3–5x is well above break-even. Growth-first scales above the scale zone.
- LTV justifies thinner first orders only within the payback period the cash allows.
- Raise AOV (bundles, quantity breaks, shipping threshold) before squeezing costs.
- Markets often top out ~$500–700/day: go broader (mass-appeal creative) or add a persona bucket (own ads, page, maths).
