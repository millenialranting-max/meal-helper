# Benchmarks and rules (from the Meta Ads Playbook, 5 Sergio C / ADVT videos)

## Business numbers (per client — ask if unknown)
- AOV = revenue ÷ orders
- Margin per order = AOV − product − fulfilment − payment fees
- Break-even CPA = margin · Break-even ROAS = AOV ÷ margin (e.g. 100 ÷ 60 = 1.67x)
- Target CPA: leaves the profit the client wants · Scale zone ≈ 1.5× break-even ROAS (derived)

## Funnel benchmarks — walk top-down, fix the FIRST failure only
| Stage | Metric | Healthy | If it fails, check |
|---|---|---|---|
| Attention | CTR (all) | ≥ 2% (aim 3%+) | Hook, first frame, lead with customer problem |
| Interest | Link CTR ÷ CTR (all) | ≥ 50% | Benefit clarity, offer, CTA → copy test |
| Cost | CPM | ~$28–30 ($50–70 new pixel) | Judge with CTR, never alone |
| Page load | Landing page views ÷ link clicks | ≈ 90%+ (assumption) | Speed, mobile, pixel, accidental clicks |
| Buying intent | Add to cart ÷ page views | ≥ 10% | Ad-page match, reviews, in-use photos, price, CTA → landing page test |
| Cart | Checkouts ÷ carts | ≥ 50% | Shipping shown late, upsell clutter, hidden mobile button |
| Checkout | Purchases ÷ checkouts | ≥ 50% | Payment options, trust, delivery; BOF reviews / 5% off 24h |
| Result | CPA vs target / break-even | ≤ target | Raise AOV first (bundles, quantity breaks, shipping threshold) |

## Judgement rules
- Never judge an ad on tiny data: a creative-test ad needs ≥ 1,000 impressions (800 on a new pixel, 2–3k if budget allows). 5x ROAS on $12 is not a winner.
- "Most sales" isn't proof if the ad got most of the spend. Sort by spend, compare ads at similar exposure.
- High CTR with a big drop to link CTR = attention without intent (the 10.9% CTR ad that sold nothing).
- Every ad must earn its keep: meaningful spend + CPA consistently above target → off.
- Ads live must match budget: ~$30/day → 1–3 ads; $100–700 → 2–5 proven winners; $1,000+ → more + weekly tests.
- Budget split: 80–90% prospecting, 10–20% retargeting. Middle-funnel retargeting is judged on clicks only; bottom on sales.
- Tests run in separate campaigns; only ads that beat current winners move into the main campaigns.
- Scale in $10–20/day steps only above target; never jump budgets on one good day.
- Fatigue signals: CTR falling, CPM and frequency rising on a long-running winner → brief a variation (new hook, creator, format, offer, message or angle — one change).
- Results swing around $500–700/day → add a persona bucket (own ads, page, maths) or broader mass-appeal creative.
