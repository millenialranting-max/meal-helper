0–1Before any campaign: numbers and setup

0 · Business numbers (use the one-pager)

  • AOV, costs per order → margin
  • Break-even CPA = margin · Break-even ROAS = AOV ÷ margin
  • Target CPA / ROAS (≈ 1.5× break-even ROAS) and goal: profit or growth
  • Daily budget → ads you can support (~$30 = 1–3 ads)

1 · Account setup

  • Pixel on the site = dataset selected in Ads Manager (check with Meta Pixel Helper); Purchase event fires with value
  • Save the column preset: CTR (all), link CTR, CPM, CPC, content views, adds to cart, checkouts, purchases, ROAS, 3s plays
  • Build custom audiences: 50% video viewers, IG/FB engagers, site visitors, add to cart, purchasers
  • Note funnel baseline in Shopify and walk checkout on a phone

2Get the creatives to test

Existing account → mine what you already paid for

  • Ads Manager → Ad level, last 6–12 months, sort by amount spent (not ROAS)
  • Keep ads with meaningful spend ($300–1,000+) near target CPA
  • Add "shadow" ads: low spend but strong link CTR or cheap CPM
  • Shortlist 8–15 → they go into campaign #1
  • For each winner note: format, idea, hook, selling point → this is your next brief

New account → make 5–15 from customer evidence

  • Read reviews, comments, tickets, Reddit, competitor reviews: what they want, what stops them, what they've tried
  • One problem = one angle = one sentence per ad
  • Show every claim visually; real phone footage beats polish
  • Mix formats: e.g. 2 static, 3 UGC, 2 carousel, 2 demo/infographic
  • Fewer ads if budget is small (see step 3 maths)

3Campaign #1: Creative Test (CT)

CT · Creative test goal: find the 2–5 ads with the cheapest attention that also sell
CampaignBuying type Auction · Objective Sales · Advantage+ catalog off · Campaign budget (CBO) $30/day+ · ignore campaign score
Ad setAudience broad (no interests/age/gender unless product is gender-specific) · Acquire new customers · Conversion location Website · Maximise number of conversions · Event Purchase · Attribution 7-day click / 1-day view · Dynamic creative off · placements default · no end date
AdsYour 5–15 shortlisted ads · URL = homepage for now (tested later) · one headline + text each
RuleSelect only these ads → More → Create rule → Turn off ads when impressions > 1,000 · schedule Continuously (800 on a new pixel with $50–70 CPM, 2–3k if budget allows)
How longDays = ads × CPM × (cap ÷ 1,000) ÷ daily budget → e.g. 8 ads × $30 × 1 ÷ $30 = 8 days. Too long? Test fewer ads.

4Pick the winners: the KPI checks, in order

Reached cap?≥ 1,000 impr.
CTR (all)≥ 2–3%
Link CTR≥ ½ CTR, small gap
CPM~$28–30, cheaper wins ties
Buyingcarts, sales, CPA ≤ target

✅ Winner

Passes every check. Rank by cost per link click and buying behaviour. Example: 38 clicks vs 8 clicks on the same 1,000 impressions.

⚠️ Not a winner

5x ROAS on $12 of spend · "most sales" when it was the only ad Meta funded · 10.9% CTR but no sales (catches attention, doesn't sell).

📦 Where they go

#1 → copy + landing page tests · #1–3 → prospecting (step 7) · #4–5 → middle retargeting · #6–8 → bottom retargeting (only if CTR ≥ 2%). Turn everything else off.

CampaignSales · ABO, equal budget per ad set

6Troubleshoot: nothing fully healthy? Walk the funnel top-down

Fix only the first "no", then re-check. More budget or new ads won't fix a leak further down.
1 CTR (all) ≥ 2%?
no →
Ad doesn't stop the scroll
→
New hook / first frame; lead with the customer's problem; retest in CT
2 Link CTR ≥ ½ CTR?
no →
Attention, no intent
→
Copy test (#2); clearer benefit, offer and CTA; show what they're buying
3 Page views ≈ link clicks?
no →
People never see the page
→
Page speed, mobile layout, pixel/tracking, accidental clicks
4 Add to cart ≥ 10%?
no →
Page doesn't continue the ad
→
Landing page test (#3); match ad promise; reviews + in-use photos; bolder CTA; check price
5 Cart → checkout ≥ 50%?
no →
Friction in the cart
→
Show shipping early / free-shipping threshold; remove upsell clutter; checkout button visible on mobile
6 Checkout → purchase ≥ 50%?
no →
Last-step doubt
→
Payment options, trust badges, delivery times; bottom retargeting with reviews or 5% off for 24h
7 CPA ≤ target?
no →
Numbers don't work
→
Raise AOV first: bundle, quantity break (2 for −5%, 3 for −10%), add-on at checkout
All "yes" → go to step 7 ↓

7Launch the main account: campaigns #4–6

#4 Interest test one audience per ad set
CampaignSales · ABO · name ad sets after the interest
Ad sets$10–20/day each · Audience → "Further limit reach" → one interest only (never stack untested ones) · winning ads + copy + URL
Pick interestsWhat buyers do, not the obvious category: e.g. matcha, yoga and Whole Foods beat Lululemon/Nike; blackout blinds → infant, diaper, trucking
NextCut interests that don't convert in 2–3 days · stack interests that won alone into one bigger ad set

CampaignSales · Advantage+ (default audience) · ~80–90% of budget together with #4
Ads3–4 winners from CT, winning copy, winning URL. Nothing untested.
WhyMeta finds buyers; you control what it shows
#6 Retargeting (RT) 10–20% of budget

8Scale and keep it healthy

How to grow

  • ROAS above target? Add $10–20/day at a time. Never jump a 16x ad to $150/day.
  • Use new budget for a new audience or a new creative test
  • Branch winners one change at a time: new hook · creator · format · offer · message · angle
  • Swings around $500–700/day? Add a persona bucket with its own ads, page and numbers (e.g. hunters vs compression-sock buyers), or go broader with mass-appeal creative
  • Don't chase an 8x target when 3–5x is well above break-even

Weekly loop (every client)

  • Pull last 7 days: CTR, link CTR, CPM, carts, checkouts, purchases, CPA
  • Run the step 6 tree; fix only the first "no"
  • Turn off ads with meaningful spend above target CPA
  • Fatigue check on winners: frequency and CPM up, CTR down → brief variations
  • Log what was tested and what won → next creative brief
  • Budget decision: scale, hold, or fix
